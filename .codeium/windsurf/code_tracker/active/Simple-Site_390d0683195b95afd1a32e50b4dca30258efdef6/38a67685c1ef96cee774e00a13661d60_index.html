Step-by-Step Terminal Guide

Follow these steps to create and manage your project using the Terminal:

  1. Open Terminal: Press Command (‚åò) + Space, type "Terminal", and press Enter.
  2. Check Current Directory: Type pwd and press Enter to see your current working directory.
  3. List Directory Contents: Use ls to view files and folders in the current directory.
  4. Navigate to Desktop: Type cd ~/Desktop to move to your Desktop directory.
  5. Create Project Folder: Type mkdir SimpleSite to create a new directory for your project.
  6. Verify Folder Creation: Run ls to confirm your new folder appears in the list.
  7. Enter Project Directory: Type cd SimpleSite to navigate into your project folder.
  8. Verify Location: Your prompt should now show ~/Desktop/SimpleSite % indicating you're in the correct directory.
  9. Create Project Files: Type touch index.html index.css to create your main files.
  10. Create Images Directory: Type mkdir Images to create a folder for your images.
  11. Verify File Creation: Run ls to confirm all files and folders are created correctly.
  12. Take Screenshot: Press Command (‚åò) + Shift + 5 to take a screenshot of your setup.
  13. Move Screenshot to Project: Type mv ~/Desktop/Screenshot\ .png ~/Desktop/SimpleSite/Images/ to move your screenshot.
  14. Access Images Directory: Type cd Images to navigate to the Images directory, then ls to verify your screenshot is there.
  15. Open in VS Code: Type code . to open the current directory in VS Code, or open it manually from your Applications folder.
